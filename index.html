What Comes In Off the Street

analyze-traffic analyses network traffic patterns from a CSV file or a PCAP capture, a purpose the source files under data analysis and reporting. This panel names both arrivals without ranking one above the other, because the source treats them as two doors into the same columns.

For CSV the columns are Source IP, Destination IP, Source Port, Destination Port, and Protocol, and the filters match on those columns. For PCAP the tool parses the capture itself, in the Python standard library, into those same columns plus Timestamp and Length. Both byte orders are read, and both timestamp resolutions, microsecond and nanosecond.

Frames the Bench Can Take

The link types are listed exactly as documented: Ethernet including VLAN tagged frames, raw IP as link types 101 and 12, Linux cooked capture v1 and v2 as 113 and 276, and loopback as 0. IPv4 and IPv6 packets are decoded for source and destination addresses, protocol, and TCP, UDP, or SCTP ports. Protocol is recorded as a name among TCP, UDP, ICMP, ICMPv6, IGMP, and SCTP, or as the IP protocol number for anything else.

Packets that are not IP, such as ARP, are skipped and counted in the log. Other link types are not supported.

A Damaged Capture Stops the Job

A truncated or malformed capture is an error and the run exits 1, never reported as an empty result.

A reader deciding whether to trust an empty looking report needs that line before any filter is touched, so it stands on its own ruled line on this bench.

Pins in Their Recesses

-hShows the help message and exits.
-oGives the path to the output report file and defaults to stdout.
-fGives the type of the input file, csv or pcap. A truncated or malformed capture exits 1.
-ipFilters traffic by a specific IP address.
-pFilters by a specific port number.
-protoFilters by a specific protocol, for example TCP or UDP.
-nSets the number of rows to process.
--src_ipFilters by source IP.
--dst_ipFilters by destination IP.
--src_portFilters by source port.
--dst_portFilters by destination port.
